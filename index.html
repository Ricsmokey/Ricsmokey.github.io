Task API — CRUD REST API

Problem: Needed a working backend service to manage a to-do list with full CRUD operations, backed by real persistent storage rather than in-memory data — then leveled it up to run in a containerized, production-style setup.

What I did: Built a REST API in FastAPI with endpoints for creating, reading, updating, and deleting tasks. Started with SQLite for simplicity, then containerized the app with Docker and migrated to PostgreSQL, orchestrated via Docker Compose with a single command. Configuration handled through environment variables.

What came of it: A fully working, containerized CRUD API with interactive Swagger docs and verified data persistence across container restarts. View the repo →
